## Versioning conventions
| Type | Convention |
|---|---|
| Templates (packages) | Dated subfolders: `YYYY-MM-DD - LATEST/` · `- DRAFT/` · bare-date superseded · `99 - old/`. Docs inside clean-named (folder carries the date). |
| Policies | Same dated folders; **published** ones also keep `00 - Published/` — the live publish-to-web source (stable file ID, edited in place). |
| Single docs (subprocessor list) | Dated `- LATEST` files + bare-date history. |
| Publishing | Policies publish via Google Docs "Publish to web" behind `normain.com` redirects; the `00 - Published` file ID never changes, so live links never break. |
