# Caveman

> Open-source email client. Me handle inbox. Inbox gone. Done.

## Email Basics
- Gmail-only (Gmail REST API + OAuth2)
- Native threading via API (no reconstruction needed)
- Delta sync via History API + Pub/Sub push notifications
- Rich text compose (bold, italic, lists, links, inline images)
- Attachments
- Multi-account support
- Unified inbox

## Inbox Zero Workflow
- Split inbox (configurable categories)
- Snooze & reminders (via Convex scheduler)
- Send later / scheduled send (via Convex scheduler)
- Undo send
- Mute threads

## Collaboration
- Shared threads (team view, Convex reactive queries)
- Internal comments on threads
- Team reply indicators (who's typing)

## Tech Stack
- **Frontend**: React SPA
- **Backend**: Convex (reactive DB, scheduled functions, HTTP actions)
- **Email**: Gmail REST API
- **Auth**: Google OAuth2 via Convex auth (refresh tokens stored in Convex)
- **Push**: Google Cloud Pub/Sub → Convex HTTP action webhook
- **Sync flow**: Pub/Sub fires → Convex action calls History API → writes deltas to Convex tables → UI updates reactively
