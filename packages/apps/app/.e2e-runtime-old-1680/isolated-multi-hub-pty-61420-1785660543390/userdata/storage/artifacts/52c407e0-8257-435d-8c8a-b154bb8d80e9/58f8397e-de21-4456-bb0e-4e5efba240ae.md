## Root Cause

The `normain` repo has an active ruleset on `main` (id `13779853`, "Main branch rules") that requires:
- `🔍 Lint & Test` status check (GitHub Actions, integration_id 15368)
- 1 approving PR review
- Squash-only merges, linear history

`statusCheckRollup` on every recent merged PR is `SUCCESS` — checks ARE running and passing. But the ruleset has bypass actors with `bypass_mode: always`:

| Bypass actor | actor_id | Type | Mode |
|---|---|---|---|
| RepositoryRole 5 (Admin) | 5 | RepositoryRole | always |
| `normain-ci-bot` (app 3114741) | 3114741 | Integration | always |
| **PhilipNgo** | 34343658 | User | **always** |
| **redsuperbat** (Max Netterberg) | 44667637 | User | **always** |

PhilipNgo and redsuperbat author **100% of recent merges** (last 30d: 87 + 69 = 156). They routinely self-merge (e.g. PR #1966: author = merger = redsuperbat, no review event). Vanta interprets `bypass_mode: always` as "required-checks rule is not effectively enforced for this PR" → flags every merge.

## bypass_mode reference

| Mode | Meaning |
|---|---|
| `always` | Actor bypasses the rule on every push/merge, no extra step. Rule effectively does not apply. |
| `pull_request` | Actor must explicitly request bypass per-PR (logged on the PR). Direct push still blocked. |

## Solution

**Single fix clears both findings.** Remove `bypass_mode: always` for the two user actors.

| Change | What | Effect |
|---|---|---|
| Remove user bypass | Drop actor_id 34343658 + 44667637 from ruleset 13779853 | PRs by these users now subject to required `Lint & Test` and 1 review |
| Keep Admin role bypass | RepositoryRole 5 stays | Emergency override, audit-logged |
| Keep `normain-ci-bot` bypass | App 3114741 stays | Release/CI commits unaffected |
| Optional hardening | Set Admin bypass to `pull_request` mode | Forces explicit per-PR bypass, fully logged |

One PR / config edit closes both Overdue + Upcoming findings; Vanta resyncs ~daily and recomputes both cohorts together.
