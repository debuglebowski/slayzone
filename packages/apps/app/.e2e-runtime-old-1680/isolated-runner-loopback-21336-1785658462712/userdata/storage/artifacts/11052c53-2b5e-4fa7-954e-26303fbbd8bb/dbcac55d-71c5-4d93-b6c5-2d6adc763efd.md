# Engineering Operation Procedures — File Description

**Normain Engineering Operation Procedures** (v1.1.0) — the internal standard for how Normain's engineering org develops, deploys, and operates the service. Used as ISO 27001:2022 evidence for the Vanta test `eng-operating-procedures`.

Covers: development process (GitHub Flow, issue tracking, code review — review required for all merges, no exceptions), QA & testing (unit/integration/E2E, test-data rules), deployment (CI/CD, staging, rollback), monitoring & alerting (SLIs/SLOs, runbooks), incident management (severity, on-call, postmortems), infrastructure (Terraform/Azure, secrets in 1Password), and vulnerability management.

Maintained in Google Drive; exported to PDF for evidence. Reviewed annually.
