# AI Provider Tycoon — Situation Catalog

Concrete list of situations injected by the simulation. See **Situation Rules** asset for the underlying rules (frequency, severity, polarity, counters).

## Frontier model release (NPC)
An NPC publishes a model that raises the public quality bar. Your relative quality drops; demand shifts.

| | |
|---|---|
| **Polarity** | Global-Negative |
| **Severity** | Minor → Critical |
| **Targeting** | Global |
| **Counters** | High recent research spend (reduced severity) · Frontier positioning (smaller brand hit) |

## GPU price spike
Server costs increase for some duration.

| | |
|---|---|
| **Polarity** | Global-Negative; flips to Conditional-Positive for stockpile holders |
| **Severity** | Minor → Major |
| **Targeting** | Global |
| **Counters** | Efficiency upgrades (reduced cost increase) · Pre-bought server stockpile (sell into the spike) |

## Regulatory action
Compliance cost imposed, or a market geo restricted. Hits players without certifications/privacy.

| | |
|---|---|
| **Polarity** | Conditional-Negative |
| **Severity** | Minor → Critical |
| **Targeting** | Global or targeted |
| **Counters** | Certifications (unlock gated segment) · High Privacy level (null, or flip to Conditional-Positive) |

## Viral incident
A public failure triggers a brand hit. Biased toward low-reliability players.

| | |
|---|---|
| **Polarity** | Conditional-Negative |
| **Severity** | Minor → Major |
| **Targeting** | Targeted |
| **Counters** | High Reliability spend (reduced fire probability) · Incident response readiness (reduced brand impact) |

## Open-source release
A free model floods a quality tier. Demand at that tier collapses for paid offerings.

| | |
|---|---|
| **Polarity** | Global-Negative; flips to Conditional-Positive for OSS movers |
| **Severity** | Major |
| **Targeting** | Global |
| **Counters** | Frontier positioning (above the affected tier) · Open-source / community moves (absorb brand halo) |
