# Malware protections deployed — "Not applicable" justification

**Vanta test:** Malware protections deployed (`anti-malware-in-use`)
**Framework:** ISO 27001:2022
**Owner:** Kalle Hansson
**Prior cycle:** Marked "Not applicable" in ISO 27001:2022 audit, Prescient Assurance, window Jul 1 2024 – Aug 2 2025.

## Justification

Normain operates no self-managed servers or bastion hosts. All production workloads run on fully managed Azure PaaS/serverless services, where the OS layer (including anti-malware) is Microsoft's responsibility. There are no host operating systems under Normain's control on which to deploy anti-malware, scheduled scans, or external-media scanning. No in-scope systems exist for this control.

## Must verify before submitting

This rests on one fact: that there are genuinely no Normain-managed VMs/servers (Azure VMs, containers on self-managed hosts, jump boxes). If any exist, N/A does not hold and anti-malware evidence is required instead.
