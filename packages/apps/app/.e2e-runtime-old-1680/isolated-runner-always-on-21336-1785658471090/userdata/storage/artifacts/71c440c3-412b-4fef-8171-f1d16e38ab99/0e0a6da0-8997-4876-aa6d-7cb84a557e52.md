## 2 · Solution overview

Two parallel tracks: **clear the 47 (audit-pass work)** + **harden the control (durable fix)**.

### 2.1 Clear the 47 — retroactive justification

Vanta accepts a documented exception with management sign-off in lieu of the missing approval.

| Step | Owner | Effort |
|---|---|---|
| Bulk-export the 47 PRs (number, author, date, title, link) into one register | Kalle | 30 min |
| Write **one** management exception memo covering all 47 — rationale: "pre–branch-protection period, two-person team, no approver pool available; controls implemented 2026-03-11 with zero recurrence". Sign as CTO. | Kalle | 1 h |
| Attach memo as evidence to the Vanta finding; mark each of the 47 entities as "exception documented" | Kalle | 1 h |
| Optional: post-hoc code review of the 31 debuglebowski PRs by redsuperbat / PhilipNgo with retroactive comment | one engineer | 2–4 h |

ISO/SOC2 auditors generally accept a single bulk exception when the underlying control gap has been closed and there's no recurrence — the 0 post-ruleset count is the evidence that lands this.

### 2.2 Harden the control — durable fix

| Action | Why | Effort |
|---|---|---|
| Tighten `normain` ruleset: enable `require_last_push_approval`, `dismiss_stale_reviews_on_push`, `require_code_owner_review` | Closes "approve, then push more, then merge" loophole | 15 min |
| Add `CODEOWNERS` to `normain` (e.g. all paths → `@redsuperbat @PhilipNgo` for Kalle's PRs; reciprocal) | Forces a real reviewer set when team is small | 30 min |
| Trim bypass actors: remove individual user bypasses (PhilipNgo, redsuperbat); keep only admin role + integration. Document the integration. | All 3 humans can currently bypass → defeats control on paper | 15 min |
| Apply same ruleset to **normain-infra** | Currently unprotected; future merges hit same finding | 30 min |
| Apply lighter ruleset (PR + linear history) to `normain-alpha`, `-beta`, `-insights-demo`, `-frontend-libraries`, `-standard-legacy` — or formally archive them | Removes from Vanta's scan surface | 1 h total |
| Promote ruleset to **org-level** so new repos inherit | Prevents recurrence | 30 min (needs `admin:org` scope) |
| Add weekly check listing bypass-mode actors per repo | Detect drift | 1 h |

**Total durable-fix effort: ~½ day.** Audit-clear effort: ~½ day.
