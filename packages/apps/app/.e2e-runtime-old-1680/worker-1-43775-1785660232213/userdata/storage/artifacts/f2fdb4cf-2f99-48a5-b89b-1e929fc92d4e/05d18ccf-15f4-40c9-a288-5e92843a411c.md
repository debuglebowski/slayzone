# UC04b — Contract Clause Sweep at Scale (URLs)

**Persona**: Legal ops, M&A counsel, or general counsel managing a portfolio of contracts.

**Scenario**: Across a bundle of **100+ contracts** (real customer scale — most enterprises have hundreds to thousands), find every change-of-control clause, limitation-of-liability cap, IP assignment provision, termination-for-convenience clause, indemnification scope, and assignability restriction. Output is a per-contract comparison table.

**Input format**: URLs to publicly hosted contracts on SEC EDGAR — no files downloaded. Tests competitors' ability to fetch + parse remote HTML at scale.

**Question types**:
- Exhaustive ("find every X across the bundle")
- Classification (clause type, risk tier)
- Clause-level citation fidelity
- Cross-contract pattern detection (e.g. "which contracts have non-standard IP assignment?")

**Sample docs (150)**: SEC EDGAR — publicly filed material contracts across companies (license agreements, supply agreements, SPAs, master service agreements, employment agreements). Distribution covers 8 clause types across industries.

**What this tests**: Repeat-mode scale ceiling. Most competitors degrade past 20–50 sources (URL fetch caps, context window saturation, latency walls, indexing failures). Citation fidelity at clause-level across hundreds of remote docs is the second wedge. URL-based input also exposes tools that only support file upload.
