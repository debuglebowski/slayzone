## Suggested sequencing

1. Lock [Action Schema](asset:e0f3dc31) + finalize [Actions Catalog](asset:a3a67c22) effects.
2. Pin economic formulas (the **Models** folder) + situation magnitudes.
3. Fill in [7. Player State](asset:3bfc1d6f) — drives the agent input shape.
4. Build tick loop with stub agents (architecture in [6. Implementation](asset:52c166c2)).
5. Wire real BYOK calls.
6. Bolt on throwaway GUI (data-driven).
7. Playtest, tune, iterate.
