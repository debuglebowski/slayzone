## Phase scope

Add the "Server URL" setting and a Local-vs-Remote toggle.

**Tasks:**
- [ ] Add react-query (TanStack Query) to renderer via `@trpc/react-query`. Memory note: `useTasksData` exposes `window.__slayzone_refreshData` — keep this contract working (or migrate callers).
- [ ] tRPC client points at WS URL. Local mode: `ws://localhost:<embedded-port>`. Remote mode: user-entered URL.
- [ ] **Local mode** behavior: Electron main starts the embedded server in-process (same code as `@slayzone/server` pkg, imported as a lib). Renderer connects via WS to localhost. Server stops when Electron exits.
- [ ] **Remote mode** behavior: Electron main does **NOT** start the embedded server. Renderer connects to user-supplied URL. Health check on connect.
- [ ] **Embedded-server failure handling**: if the in-process server fails to start or crashes in local mode, **auto-restart with exponential backoff**. Surface a user-visible error after repeated failures.
- [ ] Settings UI: "Server URL" field + Local/Remote toggle. Switching modes prompts reload. "Migrate data" wizard visible if switching from local to remote (Phase 5).
- [ ] When in remote mode: hide Electron-only features (browser panel via WCV).

**Done criteria:** Electron app works identically to today in local mode (no perceptible regression). Switching to remote URL works against a `npx @slayzone/server` running elsewhere.
