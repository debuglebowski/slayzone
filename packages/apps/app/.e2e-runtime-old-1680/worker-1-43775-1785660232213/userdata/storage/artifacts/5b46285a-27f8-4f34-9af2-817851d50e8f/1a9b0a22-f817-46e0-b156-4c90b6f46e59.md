Screenshot of Normain's operational alert configuration, captured 2026-06-12 from **Azure Monitor → Monitor → Alerts → Alert rules** (Normain tenant, normain.com). Azure Monitor is Normain's authoritative monitoring/alerting platform.

The view shows **all 35 configured alert rules, all Enabled**, across production and development, each with its condition/threshold, severity, target resource, and signal type:

- **PostgreSQL flexible servers** (prod + dev): CPU > 80%, IOPS > 1000, memory > 85%, storage > 85%
- **Azure Managed Redis** (app, app-dev, miljogiraff, advisense): used-memory > 75%
- **Storage accounts**: availability, used-capacity, and transaction metric alerts
- **Virtual machine scale sets / AKS**: percentage-CPU alerts
- **Activity log alerts** (Advisor / Recommendation) on prod + dev resource groups

Severities range from Error (1) and Warning (2) to Informational and Verbose, routed to the configured action groups. This demonstrates that operational alerts are configured and actively monitored, supporting incident-detection and -response audit requirements.
