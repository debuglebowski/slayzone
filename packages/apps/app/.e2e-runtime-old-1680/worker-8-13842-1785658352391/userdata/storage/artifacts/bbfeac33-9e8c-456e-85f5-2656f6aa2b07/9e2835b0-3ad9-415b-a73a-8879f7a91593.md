- DC 3.6 lists **Stripe** (self-serve billing). The doc declares the **Vendor Master Sheet** the register of record (DC 3.5). Stripe is **not in the Vendor Master Sheet** (confirmed against full vendor column).
- Self-contradiction an auditor will catch. **Action:** either add Stripe to the Vendor Master Sheet (+ DPA Appendix B if it's a subprocessor) or remove it from DC 3.6 if not actually used.

### 2. Firecrawl in the customer-input data path but not in the subprocessor tables
- DC 3.2 says customer-supplied URL ingestion uses **Firecrawl** (it fetches external web content into the platform). Firecrawl **is** an approved vendor in the Vendor Master Sheet, but it does **not** appear in DC 3.5 (production-path subprocessors / DPA Appendix B) or DC 7.
- If Firecrawl receives customer-supplied URLs/content, it is arguably a production-path subprocessor requiring disclosure. **Action:** confirm Firecrawl's classification and either add to DC 3.5 + DPA Appendix B or document why it's out of the data path.

### 3. "Draft cut-off date" is internally inconsistent

- **Action:** set one current cut-off date and use it consistently across DC 1 (Physical-separation note), DC 4, and DC 9.
