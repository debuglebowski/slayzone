# AI Provider Tycoon — Pricing

How prices are set and what they bind.

## Decisions

### Explicit pricing
Players set prices via the `set_price(model_id, price_per_token)` action. No auto-pricing.

Rationale: explicit pricing adds genuine strategy (price wars, undercutting) at the cost of one extra action; schema impact is trivial. The Demand Model already weights price.

## Open

- Per-token vs per-request unit (likely per-token; matches real-world AI billing).
- Price floor (zero allowed?) / cap.
- Price-change cooldown to prevent micro-spam (suggest none for v0.1; revisit if exploited).
- Pricing for unpublished models (probably not allowed — only published models are billable).
