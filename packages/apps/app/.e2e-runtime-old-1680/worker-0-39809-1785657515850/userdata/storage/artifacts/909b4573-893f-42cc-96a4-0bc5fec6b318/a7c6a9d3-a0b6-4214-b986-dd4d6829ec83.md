# Use Cases

Each use case sized to its scenario. **Per-use-case question count matters; total is whatever it ends up being** (~200 across all UCs at current sizing). Sorted by UC number.

**Mode definitions:**
- **Simple** — ask N distinct questions on a document corpus. No templated row dimension.
- **Repeat** — same question(s) repeated across N sources, output as comparison table.
- **Spreadsheet** — N question templates × dynamic input column(s). Each row's output varies based on its row's column values.

**Difficulty** = inherent test difficulty for a generic strong AI tool (corpus size × question depth × reasoning type × format complexity). Higher = harder.

**Uniqueness** = how much of this test exercises capabilities that aren't already covered by another use case. Higher = more distinctive. Subjective.

**# docs** for UC01–03 and UC08 reflects as-built corpora; UC04–07 are still stubs and show target sizing.

## Scale stress points

| Stress | Use case | Why it matters |
|---|---|---|
| **High question volume on one corpus** | UC08 (100 Qs on 29 docs, Simple) | DDQ workflow — real Normain use case |
| **Many docs, repeat mode** | UC04 (100+ contracts, 20 Qs) | Per-doc context isolation at scale |
| **Few questions, deep synthesis on huge corpus** | UC07 (10 deep Qs spanning 100+ docs) | Lost-in-the-middle, citation drift, context overflow |
| **Multimodal** | UC06 | Format ingestion ceiling |
| **Single-template Spreadsheet** | UC03 | One question × many input rows |
| **Multi-template Spreadsheet** | UC05 | Multiple questions × many input rows |

## Grading workload note

~200 questions × ~10 competitors = ~2000 grading events. LLM-judge first-pass remains feasible; human stratified sample sized to ~50 questions × all competitors.
