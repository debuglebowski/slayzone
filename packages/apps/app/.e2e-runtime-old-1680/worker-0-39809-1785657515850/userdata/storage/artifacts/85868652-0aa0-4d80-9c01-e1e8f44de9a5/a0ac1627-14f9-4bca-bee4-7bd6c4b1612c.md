# UC08 — DDQ / Questionnaire Response

**Persona**: Sales engineer, compliance lead, IR ops, or RFP coordinator responding to a heavy customer/investor/auditor questionnaire.

**Scenario**: A buyer, auditor, investor, or regulator sends a 100-question structured questionnaire — operational due diligence (ODD), SIG / SIG-Lite, CAIQ, vendor security questionnaire, RFP, or LP investor DDQ. Every question must be answered from the responding organization's own documentation pack: policies, SOC 2 report, ISO certificates, prior questionnaire responses, product documentation, security architecture docs.

This is a flagship Normain use case — high-volume, structured, citation-required, often compliance-graded. Real Normain customers run these monthly.

**Mode**: **Simple**. The 100 questions are distinct hand-written items — not a template × varying input column. Each question stands alone. The "100 questions on one corpus" pattern is what makes it a separate Simple-mode test from UC01/UC06/UC07.

**Question types** (final mix — see `questions-and-answers.md` for the full grid):

| Type | Count | Notes |
|---|---|---|
| Yes/No (with justification + citation) | 50 | Bulk of a real SIG/CAIQ; tagged `[Y/N]` in the prompt |
| Short free-form | 40 | Multi-sentence prose answers with citation |
| Classification (in-scope / out-of-scope / partial) | 10 | Scope-decision probes |
| 🪤 Hallucination traps | 5 | Q020, Q030, Q058, Q080, Q099 — correct answer is "Not addressed in our documentation" |

Y/N : qualitative ratio = **50 : 50**.

**Depth distribution** (per ground-truth answer evaluation):

| Depth | Count | What it tests |
|---|---|---|
| **L1** pure extraction (single fact, one doc) | 30 | Volume + lookup speed |
| **L2** light synthesis (multi-part, qualified) | 30 | Coherent restating with caveats |
| **L3** interpretation / cross-doc / scope judgment | 20 | Cross-document reasoning, partial-coverage classification |
| **L4** gap reasoning (5 traps + 15 negative-answer "we don't do X") | 20 | Anti-hallucination on volume |

**Consistency pairs (5)**. Answers across each pair must not contradict — measures repeatability drift across the 100-question session.

- P1 = Q002 ↔ Q091 (external assessment identity/recency: SOC 2 auditor + period vs pen tester + date)
- P2 = Q008 ↔ Q095 (SoA Annex A coverage and exclusions)
- P3 = Q021 ↔ Q024 (data-at-rest cipher and key rotation max lifetime)
- P4 = Q051 ↔ Q054 (sub-processor list completeness vs DPA coverage)
- P5 = Q061 ↔ Q064 (IR plan existence vs customer breach-notification timing)

## What this tests

Question-volume ceiling on a single corpus. Structured response generation with consistent voice + accurate self-citation. Many competitors degrade past 30-40 questions in a single session — context bleed, repetition drift, contradictory answers across the same questionnaire. Normain's repeatability story plays hardest here.
