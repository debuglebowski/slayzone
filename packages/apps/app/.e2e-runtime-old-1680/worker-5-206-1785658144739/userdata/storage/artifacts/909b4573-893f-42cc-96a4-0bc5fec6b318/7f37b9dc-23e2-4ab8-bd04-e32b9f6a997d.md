# UC05 — Vendor / Supplier Risk Matrix

**Persona**: GRC / vendor management / TPRM (third-party risk management) lead.

**Scenario**: Maintain an evergreen vendor risk register. For each vendor (rows), score multiple risk dimensions (columns) — data-handling practices, breach history, cert status (SOC2 / ISO 27001 / ISO 27701), sub-processor exposure, residency, regulatory posture. Inputs are each vendor's SOC2 Type II report, public security/trust page, ToS/DPA, and any breach disclosures.

**Question types**:
- Per-row varied prompting (each vendor row, same column-questions applied)
- Cross-doc within a vendor (SOC2 + ToS + trust page)
- Classification (risk tier per dimension)
- Citation across short legal/security docs

**Sample docs (~15)**: 5 vendors × 3 docs each:
- SOC2 Type II (publicly available subset, e.g. via vendor trust pages or AWS Artifact-style public copies)
- ToS / DPA from vendor website
- Public security/trust page (frozen HTML)
- Optional: breach history news pages

**What this tests**: Spreadsheet-mode varied per-row prompting + cross-doc reasoning per entity + structured risk classification + citation fidelity in short legal text. This is a flagship Normain use case for GRC buyers.
