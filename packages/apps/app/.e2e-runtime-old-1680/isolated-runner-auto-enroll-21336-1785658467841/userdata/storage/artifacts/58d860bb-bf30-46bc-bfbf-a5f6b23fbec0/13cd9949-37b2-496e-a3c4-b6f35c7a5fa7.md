# Create the "Marketplace Customer Decommission" Linear template

Standard issue template on the **Internal Workflows** team. Marketplace-only.

## Steps

1. Settings → Your teams → **Internal Workflows** → **Templates** → **New template** → **Standard**.
2. **Name**: `Marketplace Customer Decommission`
3. **Title**: `Marketplace Decommission: {customer} ({slug})` — select the two `{...}` tokens and apply Placeholder formatting (`Aa` icon → Placeholder).
4. **Description**: paste the body below.
5. **Priority**: Medium. Save.

## Description body

```markdown
[Runbook](https://docs.google.com/document/d/1xXZSmiKPX_3cCIiSkK2KYuCy6gisyr2iVNE4MvIrRek/edit)

- [ ] Cancellation recorded
- [ ] Access blocked (T+0)
- [ ] Retention hold (T+0 → T+90)
- [ ] Customer data destroyed (T+90)
- [ ] Closed out
```
