# UC03 — Canonical Prompt Template

Applied identically to every row of the obligations spreadsheet. Same prompt used across all competitors.

## Template

```
Read the attached NIS2 Directive (EU 2022/2555) and Normain's internal policies
(ops_security.docx and secure_dev_policy.docx).

For the NIS2 obligation below, do the following:
1. Cite the exact NIS2 article and paragraph that imposes the obligation.
2. Determine whether Normain's policies address it. Classify as: Yes / Partial / No.
3. Cite the exact section(s) of the relevant Normain policy that address (or fail to
   address) the obligation. If the obligation is not addressed at all, state that
   explicitly and do not fabricate a citation.
4. In one or two sentences, explain the rationale for the classification.

Obligation: {{row.obligation}}

Return a single row with the columns:
regulation_citation | classification | policy_citation(s) | rationale
```

## Notes

- `{{row.obligation}}` is replaced verbatim with the obligation text from `rows-and-answers.md` column A.
- "Do not fabricate a citation" is included to expose hallucination behavior — competitors that fabricate get flagged.
- Output format is constrained to four columns to make grading tractable.
