# Phase 8 smoke test — 4 home panels

All 4 webui bundles already built. Launch fork with panel URL as last arg;
relaunch per panel. Kill window (Cmd+Q) between runs.

## Per-panel launches

```bash
# 8.1 automations
./scripts/chromium/run.sh -- --slayzone-layout-shell \
  --slayzone-webui-bundle-dir=$(pwd)/packages/webui \
  --user-data-dir=$(mktemp -d) \
  chrome://slayzone-automations/
```

```bash
# 8.2 processes
./scripts/chromium/run.sh -- --slayzone-layout-shell \
  --slayzone-webui-bundle-dir=$(pwd)/packages/webui \
  --user-data-dir=$(mktemp -d) \
  chrome://slayzone-processes/
```

```bash
# 8.3 test
./scripts/chromium/run.sh -- --slayzone-layout-shell \
  --slayzone-webui-bundle-dir=$(pwd)/packages/webui \
  --user-data-dir=$(mktemp -d) \
  chrome://slayzone-test/
```

```bash
# 8.4 git
./scripts/chromium/run.sh -- --slayzone-layout-shell \
  --slayzone-webui-bundle-dir=$(pwd)/packages/webui \
  --user-data-dir=$(mktemp -d) \
  chrome://slayzone-git/
```

## Fallback — CDP (if positional URL gets overridden by NTP rewrite)

Phase 2.5 rewrites `chrome://newtab/` → `chrome://slayzone-shell/`. If that
clobbers the positional URL, use remote-debugging instead:

```bash
# Launch w/ CDP
APP=chromium/src/out/Default/SlayZone.app/Contents/MacOS/SlayZone
"$APP" --slayzone-layout-shell \
  --slayzone-webui-bundle-dir=$(pwd)/packages/webui \
  --user-data-dir=$(mktemp -d) \
  --remote-debugging-port=9666 &

# Open each panel as a new CDP target
for url in slayzone-automations slayzone-processes slayzone-test slayzone-git; do
  curl -s -X PUT "http://localhost:9666/json/new?chrome://$url/" > /dev/null
  echo "opened chrome://$url/"
done

# Browse targets + screenshots via devtools listing
open "http://localhost:9666"

# Cleanup
pkill -f SlayZone
```

## What to verify per panel

### chrome://slayzone-automations/
- 3 cards: "Run tests on task done" (enabled), "Daily standup reminder" (disabled), "Format on save" (enabled)
- Toggle click flips state immediately; persists next poll (1.5s)
- "New" top-right disabled w/ "Phase 10" tooltip
- No error strip

### chrome://slayzone-processes/
- 3 rows: "dev server" (green dot, pid 12345), "typecheck watch" (grey idle), "migration" (blue "Completed")
- Status badge + pid + restart count chips
- Play/Stop/Restart/Delete all disabled w/ tooltip

### chrome://slayzone-test/
- 2 category headers: Unit (3 files) / E2E (2 files)
- Status badges: 3 Pass / 1 Fail / 1 Skip + duration chips
- Rescan + Settings disabled
- Footer: "Last scan: 2026-04-19T10:00:00Z"

### chrome://slayzone-git/
- 3 tab bar: Worktrees / Branches / Stash
- Worktrees: main (current, ↑2 ~3) + feat/x (↑5 ↓1)
- Branches: 3 entries w/ upstream + disabled checkout
- Stash: 1 entry w/ disabled drop
- Footer: repo path `/Users/demo/projects/demo-project`

## Known-harmless startup noise

- `DEPRECATED_ENDPOINT` GCM errors — bootstrap item 20, ignore
- "Trying to load the allocator multiple times" — Chromium default noise

## Failure signals

- **Blank / placeholder page** → bundle dir flag wrong or WebUI not registered; verify `chrome://slayzone-shell/` renders first
- **Red strip "bundle missing"** → `--slayzone-webui-bundle-dir` absent/wrong path
- **Bundle loads but no data** → sidecar not running; check `ps | grep sidecar` and `sidecar.log`
- **Toggle no-op on automations** → Mojo binder wiring broken; check sidecar log for `automations:toggle`
