OPTION I — Move chrome to TOP of sidebar
=========================================

┌─────────────────────────────────────────────────────────┐
│  Slay🔥Zone              [filter] [display]  [···] [⚙]  │  ← top header
├─────────────────────────────────────────────────────────┤
│                                                         │
│                                                         │
│  (tree content — full height)                           │
│                                                         │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  [Boost]  [██░ Claude]  [██░ Codex]                     │  ← bottom: usage
├─────────────────────────────────────────────────────────┤
│  [+task]  [agent●3] [panel] [⊟]  [≡]                    │  ← bottom: runtime
└─────────────────────────────────────────────────────────┘

· Inverts current layout — meta + help + settings move TO
   THE TOP next to filter/display (header tree row)
· Bottom = passive readouts (usage) + state buttons +
   primary action
· Settings = last in top row
· Pros:  what-you-do (bottom) and what-you-look-at (top)
         spatially separate, top header reuses existing
         tree-header slot
· Cons:  breaks "settings at bottom" muscle memory from
         most apps, top header gets crowded if
         display+filter+more+view+settings all squeezed
