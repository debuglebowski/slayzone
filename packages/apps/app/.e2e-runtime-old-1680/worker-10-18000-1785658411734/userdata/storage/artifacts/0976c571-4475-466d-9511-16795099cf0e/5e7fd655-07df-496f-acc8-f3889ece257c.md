# Roadmap v1 — Draft

Every feature is a candidate — nothing is "done" until re-verified. Buckets are working guesses, not commitments: **Now** = actively building or next up · **Next** = queued · **Later** = deferred · **Discuss** = needs a decision before bucketing.

Each feature is tagged on two independent axes: a **Feature Category** (what it fundamentally does) and a **Customer Process Stage** (where in the customer workflow it fires). Most features land on one of each; some span multiple.

## Feature Categories

*What does this feature fundamentally do for the user?* Three categories, drawn from the product vision.

| Category | Description |
|---|---|
| **Embed expertise & Self-improve** | The expert's knowledge, judgement, and workflow packaged so Normain can apply them limitlessly — same quality every run, getting better over time. Covers onboarding, memory, templates, workflows-as-packaged-expertise, and self-improvement from feedback. |
| **Iterate & Collaborate** | The path from rough draft to client-ready output. Covers review cycles, approvals, feedback loops (human or AI), proactive input requests, and multi-party collaboration when needed. |
| **Audit, Traceability & Security** | The guarantees enterprises need to let Normain touch real work: audit trails, versioning, exportability, system-of-record behavior, and security. |

## Customer Process Stages

*Where in the customer's workflow does this feature fire?* Four stages the customer moves through on every engagement.

| Stage | Description |
|---|---|
| **Understand client** | Learning about the end client — who they are, what matters to them, what's happening in their market and regulatory environment. |
| **Collect data** | Pulling the raw material into Normain — files, integrations, web, emails, client-uploaded content. |
| **Extract insights** | Turning collected data into structured, usable outputs via workflows, search, and chat-driven analysis. |
| **Present to client** | Delivering results back in a form the client can act on — reports, dashboards, branded artefacts. |
