# State of AI 2026 — Key Insights

Source: https://2026.stateofai.dev/en-US (7,258 respondents, +73% YoY participation)

## 1. AI code generation effectively doubled in one year
- Avg proportion of AI-generated code: **28% (2025) → 54-56% (2026)**.
- 8% of respondents now report **100% AI-generated** code.
- 61% generate code with AI **daily**; "constantly" segment **doubled YoY**.
- Cross-ref: Claude Code users produce 63% AI code vs 54% for all respondents — agents drive higher AI share.

## 2. Anthropic captured willingness-to-pay (twice)
- **Claude** leads paid model usage (4,592) over ChatGPT (3,261) — even though ChatGPT has bigger user base (88% used vs 82%).
- **Claude Code** leads paid agent usage (3,700) over Copilot (2,703) and Codex (1,526). 58% pay for Claude Code.
- Claude usage grew **+26% YoY**, the biggest gain of any model.
- Pattern: ChatGPT = volume, Claude = revenue. Sentiment + paid both go to Anthropic.

## 3. The "bubble + inevitable" paradox
- **70%+ agree we're in an AI bubble** (avg 2.9/4).
- Yet **72% say AI is integral to their workflow**.
- Sacha Greif's framing: VC-subsidized cheap AI hooked everyone before labs raise prices. $0 spend bracket collapsed YoY; $100-$500 bracket expanded sharply.

## 4. Hallucinations leapfrogged from #9 to #1 pain point (+8)
- Meanwhile **prompt comprehension dropped -17%** as a pain point.
- Translation: models now understand what you want — they're just confidently wrong about delivering it.
- "Truthfulness" is the #1 missing feature, with **long-term memory #2**.
- Cross-ref with refactor reasons: "Hallucination" is now #2 reason to refactor; "variable renaming" dropped -4 (LLMs learned conventions).

## 5. China is no longer fringe
- Top 3 of "other models" in use (free-text): **Kimi, GLM, MiniMax** — all Chinese.
- DeepSeek already a top-5 mainline model (30.9% used).
- The Silicon-Valley-only AI narrative is dying.

## 6. Coding agents are eating adjacent categories
- App generators (v0, Lovable, Bolt) being cannibalized by Claude Code / Cursor.
- Chatbots being displaced by agents as primary LLM interface.
- "OpenCode" (open-source TUI) is the #1 write-in "other agent" — beats Cursor (305) at 389 mentions.

## 7. Job-displacement worry is structural, not technical
- Top quoted comment: AI doesn't have to actually replace you — **management just has to believe it can**.
- Job displacement is the #1 risk concern (3,003), but only ~45% personally feel threatened.
- Productivity opinion stayed strongly positive — devs feel useful, not obsolete; they're worried about perception.

## 8. Gender split on environmental impact is large
- Women/non-men: **58%** cite environmental impact as a top risk.
- Men: **37%**.
- Largest demographic split in the survey.

## 9. TypeScript is now the de facto AI language
- TS overtook JS as #1 language used with AI tools (5,360 vs 4,831).
- Python distant 3rd despite being "the AI language" in popular narrative — survey is web-dev biased, but the gap is notable.

## 10. Devs are skeptical of AGI hype
- Only **27% agree we'll reach AGI within 10 years**.
- Avg score 1.7/4 (disagree).
- Striking gap between AI-lab marketing and frontline-dev belief.

## 11. The refactor profile is shifting
- Avg refactor rate dropped to 47% (less is needed).
- But **"poor code style" jumped +9 to be #1 reason to refactor** — what's left to fix is mostly stylistic mismatch, not bugs.
- Tests jumped to #3 in generated code categories — devs trust AI with verification code despite hallucination being top pain. Risk: AI writing tests for AI code.

## 12. Local AI is positioning to disrupt
- **48% have tried local models**, another **31% interested**.
- Reasoning: cheaper alternative as labs raise prices (see #3); reduces datacenter dependency (links to #8).

## 13. Grok's negative sentiment is ideological, not technical
- Most-hated model — commenters cite Musk / right-wing politics, not capability.
- Notable: a frontier model's brand can be killed by its association alone.

## 14. Tool churn is high
- Avg respondent has used **4 models** but only **1.9 coding agents**.
- Model market = mature with active switching. Agent market = newer with consolidation underway around Claude Code + Copilot.

## 15. Code review is a growth vector
- "Code review & assistance" jumped **+8** to #2 use case.
- CodeRabbit leads dedicated AI review tools (707).
- But 57% still don't use AI for code review — biggest underserved category.

---
## Caveats
- Selection bias: AI-skeptics underrepresented. Sample is 88% male, 78% white, US/EU-heavy, avg 14.7 yrs experience.
- "Bubble" sentiment may track market mood more than fundamentals.
