# Network Diagram — Evidence Description

**Control:** Network diagram · **Owner:** Kalle Hansson · **Date:** 2026-06-12
**Environment:** Microsoft Azure — Sweden Central · **Source of truth:** `normain/terraform` (app-production)

## Summary
High-level production network diagram for the Normain platform on Azure. Generated from the
Terraform-defined production environment and rendered as a self-contained report. It illustrates
the network architecture, trust boundaries, components, and data flows that serve `normain.com`.

## Coverage (maps to required elements)
- **Boundary definitions:** Public edge (Cloudflare DNS, Azure Load Balancer) vs. private Azure VNet; subscription and resource-group (`rg-normain-prod-01`) boundaries shown.
- **Network devices:** Azure Load Balancer, Istio Ingress Gateway (Gateway API).
- **Subnets / segmentation:** Private VNet hosting the AKS cluster, PostgreSQL, and Redis; Key Vault and Storage reached via service endpoints.
- **Data flows:** Client → Cloudflare/LB (HTTPS 443) → Ingress Gateway (TLS terminate) → App workloads → PostgreSQL / Redis / Key Vault / Storage / Azure OpenAI; AKS → Container Registry (image pull).
- **Network zones:** Untrusted internet, public edge, private VNet, managed-data tier.
- **Security controls:** TLS/HTTPS in transit, TLS termination at the ingress gateway, private VNet connectivity, service endpoints, secrets in Key Vault.
- **Critical systems:** AKS app workloads (api + worker, per tenant), PostgreSQL Flexible Server, Managed Redis.
- **Physical location:** Azure region **Sweden Central** (EU); Azure OpenAI + Doc Intelligence in EU regions.
- **Redundancy:** Azure Load Balancer fronting AKS; managed PaaS services (PostgreSQL Flexible Server, Managed Redis) with provider-level HA.
