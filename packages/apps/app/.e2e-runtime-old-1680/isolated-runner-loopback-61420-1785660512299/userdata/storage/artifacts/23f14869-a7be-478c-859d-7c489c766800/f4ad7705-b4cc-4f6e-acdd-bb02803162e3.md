# Video Series Outline

**Goal:** promote me (know-how) + SlayZone (product).

> One-sentence self-intro opens Ep 1 — no dedicated "about me" episode.

## Audience

Mixed: developers + curious LinkedIn/social scrollers. Latter typically don't follow YouTube channels — they land on individual videos via feed. Implication: each ep must work standalone for cold viewers. Primer eps earn their place by catching curious-but-uninformed scrollers, not by serving subscriber funnel.

## Funnel

Single series, multiple parts. Every ep contains a real SlayZone moment relevant to that ep's topic — not bolt-on tie-in.

> **Deferred:** viewer promise (revisit later).

---

# Part 1 — Fundamentals

Hygiene primer for curious viewers. Coherent voice across basics.

## 1.1 AI / LLM Primer
- What an LLM actually is (intuition, no math)
- Why this moment — capability + cost curves
- Where they fail (hallucination, context, determinism)
- Why this matters for builders

## 1.2 Model Providers
**Format:** ~50% landscape, ~50% opinion.
- Anthropic, OpenAI, Google, local (Llama, Qwen, …)
- Trade-offs: capability, cost, latency, privacy
- My takes — who wins what, who's overrated, who's underrated
- How to pick per task

## 1.3 Coding Assistants
**Format:** ~50% landscape, ~50% opinion.
- Claude Code, Codex, Gemini CLI, Cursor, Copilot, Aider, OpenCode
- CLI vs IDE vs hybrid
- My daily stack + why
- Where each shines / breaks
- Limits of single-assistant workflows

# Part 2 — Skills

The reusable practices. Where the edge lives.

## 2.1 Prompting + Context
*"What you put in."*
- Prompting fundamentals — what actually moves the needle
- Anti-patterns + common myths
- Context engineering: memory, retrieval, scope
- What goes in the prompt vs what doesn't
- Long-context vs RAG vs tools

## 2.2 Agentic Workflows
*"What it does on its own."*
- Planning → tools → verification loop
- When agents help, when they hurt
- Designing tools that agents use well
- Multi-agent orchestration: coordination patterns
- Real example end-to-end

## 2.3 Debugging with LLMs
- Where they reliably help
- Where they confidently mislead
- My debugging loop

# Part 3 — SlayZone

Product-led. Lead with hook (strong take or live build) — backfill context for newcomers.

**Positioning sketch (detail later):**

- Recurring: live builds shipped on camera using SlayZone
- Recurring: roadmap + bets + against-the-grain opinions
