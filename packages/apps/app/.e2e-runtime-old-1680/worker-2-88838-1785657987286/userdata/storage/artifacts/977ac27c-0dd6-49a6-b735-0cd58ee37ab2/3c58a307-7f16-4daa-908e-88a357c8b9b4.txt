# Superhuman — Feature Reference

> Acquired by Grammarly (Jul 2025). Rebranded as "Superhuman Suite" (Oct 2025): Mail + Grammarly writing + Coda docs + Go AI assistant.

## Core Email

- **Split Inbox** — auto-categorize into VIP, Team, Newsletters, custom sections
- **Snooze** (H) — hide & resurface at chosen time
- **Reminders** — auto-follow-up if no reply within N days
- **Send Later / Scheduled Send**
- **Smart Send** — ML-optimal send time per recipient (Business+)
- **Undo Send**
- **Read Receipts** — who opened, how many times, which device
- **Recent Opens Feed** — real-time open notifications (Business+)
- **Unsubscribe** (Cmd+U) — one-key unsub + trash sender
- **Auto Archive** — AI archives low-priority mail
- **Mute** — permanently silence a thread
- **Multi-account** — switch with Ctrl+1-9
- **Rich text** — bold, italic, strikethrough, lists, quotes, colors, links, inline images
- **Works on Gmail / Google Workspace and Outlook / Microsoft 365** (not a separate provider)

## AI Features

- **Write with AI** — bullets/rough ideas → polished drafts
- **Voice & Tone matching** — adapts to your style per recipient
- **Instant Reply** — AI-generated reply suggestions
- **Auto Drafts** — pre-writes follow-ups in your voice (Business+)
- **Auto Summarize** — one-line summary per conversation, live-updated
- **Auto Labels** — AI classification (marketing, cold outreach, etc.)
- **Custom Auto Labels** — natural language label definitions (Business+)
- **Auto Reminders** — detects emails needing follow-up, generates drafts
- **Auto-Send** — rule-based AI sending on your behalf
- **Ask AI** — natural language search across inbox, calendar, web (Business+)
- **Grammarly** — tone, clarity, conciseness suggestions built into editor

## Calendar

- **Integrated sidebar** — toggle with `0`, navigate with `-`/`=`
- **Share Availability** — select slots → insert booking link
- **AI Event Creation** — auto-fills title, description, location, attendees, optimal time
- **Team availability** — see teammate free slots inline
- **Video links** — auto-attach Zoom / Meet / Teams
- **Multi-calendar conflict checking**

## Collaboration / Team

- **Shared Conversations** — live thread view with teammates
- **Team Comments** — private threaded comments on emails (invisible to recipients)
- **Team Reply Indicators** — see who's already replying
- **Team Read Statuses** — shared read receipt data
- **Team Snippets** — shared templates across org
- **Team Scheduling** — teammate availability for meetings
- **Consolidated billing & admin** (10+ users)

## Productivity

- **Command Palette** (Cmd+K) — searchable access to every function
- **100+ keyboard shortcuts** — vim-inspired (J/K nav, E archive, H snooze, R reply, C compose)
- **Snippets** (Cmd+;) — saved phrases/paragraphs/full emails with attachments
- **Superhuman Focus** — arrow-key-driven triage mode
- **Send & Mark Done** (Cmd+Shift+Enter)
- **Multi-window / multi-tab** (Cmd+N / Cmd+T)
- **Social Insight sidebar** — sender role, company, social profiles
- **1-on-1 onboarding call** with Superhuman team

## Integrations

- **Email**: Gmail, Google Workspace, Outlook, Microsoft 365
- **CRM**: Salesforce, HubSpot, Pipedrive — contact context, auto-log, add contacts (Business+)
- **Video**: Zoom, Google Meet, Microsoft Teams
- **Writing**: Grammarly (built-in)
- **Docs**: Coda (suite)
- **Browser**: Chrome extension
- No native Slack, Notion, or Zapier integrations

## Notable Limitations

- No free plan for email
- No Linux support
- No Google Groups compatibility
- Outlook support lags Gmail (no Android Outlook)
- Limited integrations outside CRM ecosystem
- Relatively expensive vs free email clients
