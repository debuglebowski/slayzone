# 🆔 uuid Risk Acceptance — Brief

## 📜 Background

`normainofficial/normain` has 1 open Vanta Medium alert against the npm package **`uuid`** (GHSA-w5hq-g745-h8pq, vulnerable range `< 14.0.0`, fix in `14.0.0`). The alert is part of the broader Vanta task _"Medium vulnerabilities identified in packages are addressed (GitHub Repo)"_ due **2026-05-25** (ISO 27001:2022 + SOC 2).

`uuid` is **not a direct dependency** — it is pulled transitively by **7 parent packages**, each calling uuid's CommonJS API (v7–v11):
- `bullmq`
- `@taskforcesh/bullmq-pro`
- `@azure/msal-node`
- `@langchain/core`
- `langsmith`
- `box-typescript-sdk-gen`

**uuid 14.0.0 is an ESM-only major release.** It removes the CommonJS exports those parents depend on and changes validation semantics. Forcing a global yarn `resolutions` pin to `^14.0.0` would 💥 crash:
- ⚙️ bullmq queue processing (job dispatch)
- 🔐 @azure/msal-node token refresh (auth)
- 🧠 @langchain/core run-tracing

That is a production-down event in exchange for closing a low-impact validation CVE. **The remediation cost vastly exceeds the residual risk** — making this a textbook risk-acceptance candidate per our Operations Security Policy.
