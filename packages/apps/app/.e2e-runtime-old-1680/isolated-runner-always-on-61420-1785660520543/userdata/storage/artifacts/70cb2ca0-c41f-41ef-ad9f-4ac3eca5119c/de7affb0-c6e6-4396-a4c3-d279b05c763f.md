# Concept C — Hybrid Two-Column

Keep narrow icon rail. Add second always-visible column with task list. Like Slack channels or Things 3.

## Behavior

- Column 1 (`w-18`): project rail (unchanged)
- Column 2 (`w-64`): task list of selected project
- Click project in col 1 → col 2 updates
- Search at top of col 2
- Group tasks by status (Active / Backlog / Done) collapsible
- Done toggle pinned at bottom of col 2
- DnD tasks within col 2 reorders; cross-project drag = move

## Pros

- Both project + task always visible — no hidden state
- Mirrors familiar pattern (Mail, Slack, Things, Linear)
- Strong cross-project DnD affordance

## Cons

- Costs ~256px of canvas always
- Zen mode needs to hide both columns
- Task count must be highly scannable (visual density matters)
